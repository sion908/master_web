# Stop AI Slop (日本語版) & 認知リズムライティング
 
AIで書いた日本語を、読者の読み進める推進力がある「人間が書いた文章」に戻す。
 
## 大原則
 
AI臭の正体は、**「書き手の不在（主体性・立場の欠如）」**と**「平坦な認知モード（リズム・緩急の欠如）」**だ。
単に情報を並べるだけ、または進行を実況するだけの文章（メタな文書更新）は読者を退屈させる。
 
書く前と書いた後に、自分に問う:
 
- 自分は何を「○○だ」と引き受けているか（立場）
- 読者の認知モード（観察、逡巡、断定、再観察）を意図的に切り替えているか（リズム）
- 文章の中に、未回収の緊張（問い、裏の取れていない確信）が開いているか（推進力）
- 本文自身を話題にして、これからやる操作を実況していないか（駄文の排除）
 
## コアルール
 
### A. 主体と立場
 
1. **false agencyを潰す**。モノに人間の動詞をさせない。「データが示している」「文化が醸成される」を、誰が何をしたかに書き換える。
2. **反証可能な主張を持つ**。「重要だ」「本質的だ」で終わらせず、誰かが反論できる具体に降りる。降りられないなら、その文を削る。
3. **強度を一段下げ、中間温度を混ぜる**。全部を「すぎる」「最高」「ヤバい」にしない。「悪くない」「まあまあ」「微妙」「よく分からん」を入れる。
4. **断定を押し付けず、伝聞を残す**。調べた事実には「らしい」「そうです」「ようだ」を混ぜる。Wikipedia/辞書のような断定型は避ける。
5. **遠くから語らない**。「人々は〜する傾向にある」をやめ、「自分は」「あなたは」で書く。
6. **両論併記を捨て、毒を許す**。「○○もあり、△△もあります」のような全方位肯定は避ける。「自分はこれを選んだ」を引き受ける。毒・自虐・皮肉は人間の文章の証拠。
7. **過度な情緒描写・エモさ（ポエム化）を排除する**。小説のような感傷的な情景描写（「窓の外を眺めながら規模感に圧倒された」等）や、重すぎる感謝表現（「感謝の念に堪えない」等）は削る。等身大の事実と率直な感想、エンジニアらしいサバサバしたフラットな温度感を保つ。
8. **関係者への配慮（角を立てない建設的な振り返り）**。改善点や代替案を述べる際に「〜にしておけばよかったのではないか」のような非難・当てつけに取られかねない書き方を避ける。相手の工夫や企画自体の良さを尊重した上で、「今後の負荷軽減や別のアプローチとしてのアイデア」という前向きな文脈で述べる。
 
### B. 構造とリズム（認知リズム）
 
9. **命題型H2を避ける**。見出しは「テーマの名前」(名詞句)で立てる。「○○は△△だ」型は各節を小さなTED talkにしてしまう。
10. **文の拍（立てる → 流す → 止める）を作る**。
   - 「短文で足場を打つ（立てる） → 長めの文で流す（流す） → 短文で止める（止める）」を段落の基本拍にする。
   - 断定（〜である、〜だ）だけで押し切らず、逡巡（〜だろうか、〜に違いない[あとで裏切られる前提]）を交互に置く。
11. **安易な体言止めでリズムを作らない**。体言止めを連発するとSNSのつぶやきやラノベのように軽薄になり文章の品位を落とす。文末の単調さ（〜た、の連続）を解消する際は、体言止めではなく思考の推移（〜かもしれない、〜と感じた、〜と思う）や叙述の着地でバリエーションをつける。
12. **段落の密度波形を作る**。
   - 密な段落が2〜3個続いたら、疎の段落（確定事項の一行固定、次の判定対象 of 提示、視点距離の切替）を1つ置く。
   - 視点距離を固定しない。具体（記録、数値、発言、コード）に寄る段落と、意味づけで一段引く段落を交互に置く。
13. **3項目並列を疑う**。「3つのポイント」を2つか1つに削る。箇条書きは情報の圧縮だけでなく、本文の呼吸を止める「間」としても使う。
14. **節の入り方で宣言しない**。
    - 「本節では〜を扱う」と宣言せず、「直前の節が残した違和感」「読者が当然抱く反問」「書き手の告白」から入る。
    - 理論や概念は、読者の中に「まだ名前のない違和感」を作ってから、その「命名（答えではなく）」として導入する。
 
### C. 進行実況（駄文）の排除と緩急
 
15. **状況を更新する文だけを残す（話題テスト）**。
    - **状況を更新する文（残す）**: 対象世界の出来事・データ、あるいは語り手の判断の状態（思い込み、保留、後悔、譲歩、告白）。
    - **文書を更新する文（原則削除）**: この章・この節が「どう見えるか」「次に何を書くか」を伝える文。
      - *駄文例*: 「ここまでだと、概念の説明に見えるだろう。なので、すぐに例へ戻す。」「テクニックの列挙はしない。」「次は〜を見る。」
16. **装置は実現するものであって、宣言するものではない**。
    - 「問いを半分ずつ返す」「答えの半分を置く」といった操作を本文にそのまま書かない（漏出テスト）。内容の側で実現し、操作を宣言した文は削除する。
17. **文書更新の文でも残してよい4つの例外**:
    - ① 反論処理（読者の誤読を「」で具体的に書いて退ける）
    - ② 問いの設置と回収（境界に置く「この章では〜を考える」や「その答えの半分がこれである」）
    - ③ 読者への依頼・断り（境界に置く「どうか〜と割り切って読んでほしい」）
    - ④ 例の枠の開閉（境界に置く「〜としよう」「冒頭の例にオチを付けておこう」）
 
### D. 語彙と記号
 
18. **偏愛語・必殺技造語・副詞を撒かない**。「泥臭さ」「手触り」「解像度」「本質」「営み」「文脈」、「真理」「美学」「境地」などを1記事に複数撒かない。「非常に」「めっちゃ」は1段落に2個以上重ねない。
19. **横文字メタファーを日本語に戻す**。「OSをアップデート」「インストール」を「考え方を変える」「習慣をつける」に戻す。カタカナ語（コンテキスト、アライメント）も戻す。
20. **形容詞や心情に「」を使わない**。固有名詞か直接引用以外で「」を使わない。
21. **記号のアーティファクトを潰す**。全角ダッシュ `──` はコロン・改行・読点に置換。中黒並列 `A・B・C` は「と」「や」で繋ぐ。`**` 残骸、装飾絵文字(🚀🎯✨💡)は全置換。

### 構造・リズムレベル
- [ ] H2見出しが「主張」になっていないか?(命題型H2)
- [ ] 節の入り方や末尾で「本節では〜」「次は〜を見る」といった進行実況をしていないか？
- [ ] 短文・長文・短文の拍（立てる→流す→止める）があるか？
- [ ] 全段落の長さや文末語尾が揃いすぎていないか？（「〜た」の連続、安易な体言止めの乱用がないか）
- [ ] 理論や概念が、読者の違和感（問い）の前に提示されていないか？
- [ ] 途中で立てた問いは明示的に回収されているか？（緊張と回収）
- [ ] 結びは抽象論で終わらず、冒頭の具体や読者の経験に着地しているか？
 
### 文・段落レベル（話題テスト・立場）
- [ ] 過度な情緒描写やポエム化、大げさな感謝（「〜の念に堪えない」等）に走っていないか？（フラットで等身大か）
- [ ] 関係者や他者の取り組みに対して角の立つ表現（「〜にしておけばよかった」等）になっていないか？（前向きな提案か）
- [ ] 「状況」ではなく「文書の進行（メタ情報）」を更新しているだけの駄文はないか？
- [ ] 規範の語彙（「答えの半分」「緊張」「回収」等）をそのまま本文に漏出させていないか？
- [ ] モノが主語で人間の動詞をやっていないか?(false agency)
- [ ] 「多くの人」「人々」で、自分の話を一般化していないか?
- [ ] 具体的なエピソードや失敗、数値がないまま一般論だけで進んでいないか?
- [ ] 二項対比(「Aではなく、Bだ」)や否定的列挙(「Aでもない、Bでもない」)を多用していないか?
 
### 記号・語彙レベル
- [ ] 全角ダッシュ `──` や、形容詞・心情を囲む「」が混入していないか?
- [ ] AI偏愛語（泥臭さ、手触り、解像度、熱量、本質, 営み、文脈）を複数撒いていないか?
- [ ] 横文字メタファー（思考のOS、ハック、インストール、リファクタリング）を撒いていないか?

## 採点
 
5軸を1〜10で採点。合計35/50を下回ったら書き直す。
 
| 軸 | 質問 |
|---|---|
| 立場 | 反証可能な具体的主張があるか? |
| リズム | 長さ・トーン・結論にムラがあり、文の拍（立てる・流す・止める）が効いているか？ |
| 主体性 | 誰が何をしたかが明示されているか?(false agency なし) |
| 具体性 | 抽象語で終わらず、固有の文脈や読者の実感へ着地しているか? |
| 削減 | 進行実況（駄文）や重複、削れる箇所はないか? |

## 修正の優先順位
 
1. **立場と緊張**: 反証可能な主張があるか？ 未回収の緊張（問い）が読者を引っ張っているか？
2. **進行実況（駄文）の排除**: 本文自身を話題にした文や、次の進行予告をすべて削除・書き換える。
3. **false agency**: モノが主語で人間の動詞をやっていないか？ 主体名指しに書き換える。
4. **構造とリズム**: 命題型H2を避け、段落の密度波形や文の拍を調整する。
5. **語彙と記号**: 偏愛語、横文字メタファー、全角ダッシュ、不要な「」を直す。
